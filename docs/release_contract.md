# Release contract

Private development precedes a coordinated public GitHub export. The NeurReps
and extended arXiv papers must link the final public repositories and exact
release versions; private URLs in this development checkout are not final paper
links. Export a reviewed source snapshot, retain attribution and licenses, and
verify every link before the manuscript is frozen for publication.

The benchmark code lives in Git. Hugging Face is a proposed later home for
versioned datasets and checkpoints with cards and hashes. Source-specific data
rights remain separate from the MIT software license. No raw financial data or
trained checkpoints are bundled in this initial development commit.

A public release requires clean-environment installation, executable examples,
training/checkpoint/sampling/evaluation commands, documented supported sizes and
numerical tolerances, meaningful tests and CI, and reproduction of its claimed
results. Separate historical reconstruction, research extensions, and validated
paper configurations. Long training or passing shape tests do not establish
fidelity to the original CorrGAN publications.
