# Coordinated release candidate

This is a prepared source snapshot, not evidence of public publication.
The gautiermarti GitHub URLs are intended destinations until verified live.
Package version 0.1.0rc2 identifies this experimental release; use
the exact Git revision and SHA-256 files, not only the version string.
Scientific modules match the audited development source byte for byte.

Financial and participant-level datasets are excluded. The CorrFlow
teaching checkpoint and data are explicitly synthetic. NOAA data have
a separate card and attribution; software licensing does not license
other source data. No protected Kaggle challenge is included.

CI is prepared but has not run on GitHub. Publishing the CorrBench
snapshot first makes the models' exact dependency pins resolvable.
Archive actual release tags and add verified identifiers to CITATION.cff
and the papers after publication; no DOI is invented here.
